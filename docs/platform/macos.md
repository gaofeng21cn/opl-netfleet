# macOS 平台实现

本文是 macOS 机制事实的当前 owner：界面宿主与资源加载、运行与进程监督、私有状态与凭据位置、
配置编辑策略、订阅来源事务、流量接管原语和打包签名。共享产品对象、选择算法、恢复顺序和界面
内容与交互分别由[产品对象](../architecture/domain-model.md)、[选择](../architecture/selection.md)、
[运行与恢复](../architecture/runtime-and-recovery.md)和[界面设计](../design/ui.md)拥有；本机构建、
启动与验证的操作入口见[macOS 开发](../development/macos.md)。

macOS 不复制选择算法，不包含透明 HTTPS 兼容插件或 LAN 网关管理。

## 界面宿主与资源加载

业务界面由 `ui/` 的 React 桌面入口提供，通过带会话认证的客户端连接本机服务；页面内容、
布局、状态语义、操作层级和宿主职责边界见[界面设计](../design/ui.md)。macOS 以 AppKit 窗口、
应用菜单、菜单栏状态项、快捷键、文件面板和生命周期实现这些职责，原生菜单只向页面发送
操作意图，UI 不直接操作核心、系统代理或 TUN。

构建时将 Vite 的静态产物装入应用 `Resources/desktop/web`，运行时不启动 Vite、不加载设备
预览桥或模拟场景；本机 Web 服务只提供固定入口和构建产物中的静态资源，不开放源码或本机目录。
桌面布局覆盖集中在 `ui/src/desktop/desktop.css`，不修改 OpenWrt 的布局；应用图标在构建时由
仓库 logo 生成 macOS 图标尺寸。

## 运行与进程监督

桌面运行由本机 Node 进程协调，UCode 微内核加载同一份模型、编译、选择与恢复业务服务。
macOS 提供平台路径、凭据、Profile、订阅、进程与 Mihomo 后端服务，明确替换 OpenWrt 实现；
不能把 UCI、procd、nft 或 APK 的状态解释为 macOS 状态。窗口关闭不等于停止代理；退出应用
必须完成自身网络状态恢复。

显式代理核心由持有桌面所有权管道的独立父进程监督，管道断开后停止并回收核心；启动时核对
持久 PID、启动时间与命令身份，清理上次自身遗留进程，不按进程名称批量终止代理。

## 私有状态与凭据

每个状态目录先取得内核文件锁，再读取或修改状态、socket 和业务代码投影；探活本身不授予
替换运行入口的权限。用户私有目录保存 policy、evidence、recovery、订阅缓存、原生配置、运行
状态及操作锁，目录与文件分别使用 0700、0600；订阅凭据和控制密钥不得进入状态摘要、日志或
仓库。

导入和备份恢复拒绝任意路径写入，候选配置先经真实 Mihomo 校验再原子保存；正在使用的配置
不能被导入直接覆盖，失败保持之前可运行状态或恢复直连。

## 配置编辑与策略所有权

结构化配置编辑复用共享配置编辑器的资源与版本投影，提交草稿起始 revision；策略合并与未知
字段保留由共享 owner 完成，macOS 不重建 policy。增强代理运行中不接受仅保存结构化配置，
需先停止或退出增强，再保存、编译并按需启用。

## 订阅来源事务

桌面添加订阅由本机 owner 下载并经真实核心校验，提交前不改现有来源。首次添加直接使用订阅
中的完整配置；只有节点列表时生成最小主入口配置。共享发现模型识别地区与出口，保存后自动
编译；过程不启动核心、不修改网络接入。一个订阅只生成一个来源，不额外复制为本地导入机场；
新增机场合并其地区映射，保留既有出口、规则和用户策略。

来源增删、启停和地址修改须先停止核心，正常订阅更新允许在运行中使用共享更新及回退链路；
失败下载保留旧缓存。已保存但无法自动识别或编译的订阅标记待配置，不报告可用。

## 网络接入

接入方式与业务运行模式相互独立：接入方式是显式代理、系统代理或 TUN，业务模式是原生直连、
Mihomo 原生代理或 NetFleet 增强代理。首次启动使用显式代理，只监听回环，不改变系统网络；
系统代理必须在核心就绪后接管；TUN 必须经过特权服务授权并读取真实核心与网络结果，只写入
`tun.enable` 不能报告接管成功。缺少权限或遇到冲突时保持原网络并返回具体原因。

系统代理与 TUN 需要安装本应用随包提供的有限特权组件并由 macOS 管理员授权，安装不等于接管
成功；显式代理不需要特权组件。每个核心与网络资源只有一个管理者，系统设置保存接管前状态，
清理只恢复仍属于当前操作的字段，第三方后续修改不得被旧快照覆盖。核心或桌面进程异常退出
必须触发网络清理，无法证明清理成功时呈现未确认，不冒充直连。退出增强恢复独立 Recovery
Profile；显式直连停止核心与调度并撤销自身接管。

## 打包与签名

应用由本地构建入口生成 `.app`，内含固定版本的 Node、UCode、Mihomo 和 yq，包内动态库使用
相对路径。当前产物为 ad-hoc 签名、未公证；源码运行与可分发应用的签名、公证是独立证据层，
构建与验证入口见[macOS 开发](../development/macos.md)。

## 本机接口

界面 HTTP 仅监听回环地址，使用每次启动生成的随机令牌，并限制来源和请求大小。私有 Unix
socket 供当前 UCode 调用平台方法，socket 和所在目录限定当前用户访问，浏览器不可使用该
接口。用户操作串行，调度器复用同一入口，平台回调不得建立第二轮选优。连接诊断只返回本应用
所管理核心的连接摘要；控制接口读取失败时报告失败，不伪装为空列表。
