# 0003：React 参考开发、原生 LuCI 落地

## 上下文

每次 UI 调整都编译并部署到 OpenWrt 会显著拖慢开发；把完整 React bundle 挂入 LuCI 又会
增加宿主、主题、认证、缓存和设备资源复杂度。

## 决定

`ui/` 的 React/Vite 应用用于本机快速参考开发，可通过只读桥接查看真实设备投影；生产只部署
原生 LuCI `view.extend`/`E()` 页面。两端共享信息结构、状态 schema、文案和交互合同，不共享
组件或 bundle，也不追求像素一致。

## 后果

视觉与交互可以在本机快速收敛，设备页面继续沿用 LuCI 生命周期和权限模型；定稿后需要把
参考面一次性翻译到原生 LuCI，并分别验证 source 与设备 DOM。

## 未采用

- 在设备动态加载或挂载 React；
- 让本地桥接转发 enable、select、refresh、disable 或配置写入；
- 为追求 1:1 像素一致复制 LuCI 主题实现。

## 重审条件

只有 LuCI 官方宿主能够稳定承载现有前端 bundle，且设备资源、认证、升级和主题兼容性均有
真实证据优于原生实现时，才重新评估生产宿主。
