# 能力与平台归属

本文是功能规划层的能力清单：每项能力属于共享业务还是平台机制，以及当前在哪些平台成立。
对象、状态、算法和界面的详细设计归 `docs/architecture/` 与 `docs/design/ui.md`；某个平台用哪些
机制落地归 `docs/platform/`。本文不记录任务、进度、日期、负责人或完成度。

「共享业务」表示一份实现服务多个平台；「平台机制」表示各平台按自身原语实现同一产品语义，
或该平台专有的部分。

| 能力 | 归属 | OpenWrt |
| --- | --- | --- |
| 机场订阅、缓存与配额 | 共享业务 | 共享实现 |
| Policy Source 编译与 Profile 产物 | 共享业务 | 共享实现 |
| 业务出口与选择算法 | 共享业务 | 共享实现 |
| 健康检查、切换门槛与选优 | 共享业务 | 共享实现 |
| Fail-Open 与恢复事务 | 共享业务 | 共享实现 |
| 状态、事件与证据投影 | 共享业务 | 共享实现 |
| 业务界面的内容与交互 | 共享业务 | 共享实现 |
| 界面宿主、资源加载与缓存 | 平台机制 | 原生 LuCI 页面与包内静态资源 |
| 进程与服务监督 | 平台机制 | procd 前台 supervisor 与薄 rpcd 适配 |
| 系统级流量接管 | 平台机制 | 透明代理、DNS 与 nft 规则 |
| LAN 网关管理（其他设备经本机接入） | 平台机制 | 有 |
| 安装、打包与更新 | 平台机制 | apk 软件包与部署 bundle |
| 实时观察面板 | 平台机制 | 后端 controller 与 Zashboard |
| 透明 HTTPS 兼容模块 | 平台机制（可选增强） | 有，不属于标准功能 |
| 桌面窗口、托盘与系统集成 | 平台机制 | 不适用 |

平台列在该平台的实现进入仓库时新增，未进入仓库的平台不预留列。
