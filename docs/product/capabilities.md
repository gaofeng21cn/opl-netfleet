# 能力与平台归属

本文是功能规划层的能力清单：每项能力属于共享业务还是平台机制，以及当前在哪些平台成立。
对象、状态、算法和界面的详细设计归 `docs/architecture/` 与 `docs/design/ui.md`；某个平台用哪些
机制落地归 `docs/platform/`。本文不记录任务、进度、日期、负责人或完成度。

「共享业务」表示业务规则由共同 owner 维护；运行服务共用源码，界面可按共同合同分别渲染。「平台机制」表示各平台按自身原语实现同一产品语义，
或该平台专有的部分。

| 能力 | 归属 | OpenWrt | macOS |
| --- | --- | --- | --- |
| 机场订阅、缓存与配额 | 共享业务与平台存储 | 共享规则；平台下载与私有缓存，支持独立额度来源及手工重置日 | 共享规则；本机下载与私有缓存，额度来自订阅响应头 |
| Policy Source 编译与 Profile 产物 | 共享业务 | 共享实现 | 共享实现 |
| Mihomo 高级网络配置（DNS、嗅探、连接、GeoData） | 平台配置 | 高级表单与同草稿专家编辑，应用后回读 | 未提供同等表单 |
| 业务出口与选择算法 | 共享业务 | 共享实现 | 共享实现 |
| 健康检查、切换门槛与选优 | 共享业务 | 共享实现 | 共享实现 |
| Fail-Open 与恢复事务 | 共享业务 | 共享实现 | 共享实现 |
| 状态、事件与证据投影 | 共享业务 | 共享实现 | 共享实现 |
| 业务界面的内容与交互 | 共享业务（共同合同） | 原生 LuCI 渲染 | React 渲染，复用本地参考面组件 |
| 界面宿主、资源加载与缓存 | 平台机制 | 原生 LuCI 页面与包内静态资源 | AppKit 宿主与 WKWebView，构建期装入静态产物 |
| 进程与服务监督 | 平台机制 | procd 前台 supervisor 与薄 rpcd 适配 | 本机 Node owner 监督核心与调度，Unix socket 回调 |
| 系统级流量接管 | 平台机制 | 透明代理、DNS 与 nft 规则 | 系统代理与 TUN，需特权组件与管理员授权 |
| LAN 网关管理（其他设备经本机接入） | 平台机制 | 有 | 不适用，只监听回环 |
| 安装、打包与更新 | 平台机制 | apk 软件包与部署 bundle | 本地 `.app`；Developer ID 分发构建与需公证验收的 DMG 入口，无自动更新 |
| 实时观察面板 | 平台机制 | 后端 controller 与 Zashboard | 诊断页读取本应用核心的连接摘要 |
| 透明 HTTPS 兼容模块 | 平台机制（可选增强） | 有，不属于标准功能 | 无 |
| 桌面窗口、托盘与系统集成 | 平台机制 | 不适用 | 原生窗口、菜单栏状态项与应用菜单快捷键 |

平台列在该平台的实现进入仓库时新增，未进入仓库的平台不预留列。
